# Discord Message Purger

a simple script that runs in your browser's dev console and deletes
messages sent by you in the specified dm/channel id

> FYI: this violates disocrd tos so use at your own risk


## How to use it

1. Open discord in your browser
2. Go to the DM or channel
3. Press `F12` and open the Console tab 
4. Paste in the whole script
5. yipee you did it!

## Does this steal my info or token?

**No.** This script does not send your token, messages or any other data to me or any 3rd party server. There are no outside network calls anywhere in the code and everything runs locally in your browser tab
